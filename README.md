# 📚 Library Book Inventory Manager

A robust Command Line Interface (CLI) application built in **Python** to manage a library's book inventory, tracking, and issuance operations efficiently. This project utilizes object-oriented programming, dictionary collections for fast lookups, and JSON file persistence.

## ✨ Features
* **Add & Manage Books:** Register new book titles, authors, and total copies, or automatically update stock when adding existing IDs.
* **Fast Search:** Look up books instantly by Title, Author, or unique Book ID using efficient dictionary mapping[cite: 1].
* **Issue & Return System:** Track book circulation by issuing available copies and handling returns seamlessly.
* **Inventory Reports:** Generate quick analytical summaries of total unique titles, physical book counts, and issued books[cite: 1].
* **Data Persistence:** Automatically saves and reloads all inventory data using a `library_inventory.json` file[cite: 1].

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Concepts Used:** Object-Oriented Programming (`Book` & `Library` classes), Collections (Hashmaps/Dictionaries), File I/O (JSON)[cite: 1].
